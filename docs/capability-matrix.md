# Format, library, and device support

This matrix describes the implementation in the current source tree. “Fixture-tested” means automated tests use generated files or simulated mounted volumes; it does not certify a reader model or firmware.

| Area | Implemented | Fixture-tested | Hardware-verified |
| --- | --- | --- | --- |
| Library formats | Store multiple files per book. Calibre format files are retained; common document and ebook formats can be imported or attached. Built-in reading supports DRM-free EPUB, MOBI/AZW/AZW3, FB2, TXT, PDF, CBZ, and CBR. | Asset indexing, content deduplication, variants, EPUB migration, Calibre imports, and CBZ page serving. Reader adapters currently have build coverage; browser/WebView fixtures are still needed. | Not applicable |
| Calibre import | Read-only import of book records, available format files, covers, normalized metadata, raw metadata, custom-column values, and raw reading-state/annotation records. Reimports use source identity; exact content matches can identify existing Attune assets. | Generated Calibre database and multi-format asset fixtures, missing files, and repeated content. | Not applicable |
| Mounted storage | USB mass-storage volumes; known profiles for Kindle, Kobo, PocketBook, Tolino, NOOK, BOOX/Onyx, and Supernote; explicitly selected unknown volumes require saved folder and format choices before sending. Per-device folder and ordered-format overrides are supported. | Simulated mounted volumes, nested folder validation, profile filtering, remembered overrides, no-overwrite copies, and transfer verification. | No broad model/firmware verification; community reports are welcome |
| MTP | macOS/Linux use libmtp; Windows uses Windows Portable Devices through a packaged helper. Storage is enumerated first and configured folders are listed lazily. Uploads avoid overwrites and verify device-reported size. | Fake transport tests cover discovery, storage enumeration, opaque IDs, folder traversal, uploads, deletion, failures, and disconnect handling. CI compiles the Unix binding and Windows C++ helper. | No physical MTP device verified. |
| Built-in reader | Reflowable: DRM-free EPUB, MOBI/AZW/AZW3, FB2, and TXT. Fixed page: PDF, CBZ, and CBR. Locators and progress are stored per asset; EPUB legacy progress is migrated. Calibre annotations/bookmarks are imported and unresolved items remain in the annotations sidebar. | Generated Calibre annotation and asset fixtures, Go route tests, TypeScript checks, and production build. Browser/WebView and broad format regression fixtures remain needed. | Desktop WebView behavior and format fixtures still need broader verification |
| Calibre export | Not implemented. | None | None |

Profile folders and format lists are conservative defaults based on common sideload workflows. A detected brand name is not proof that every model supports every listed format. Calibre import is read-only; export and collection editing are not implemented. For a useful compatibility report, include device model, firmware, operating system, connection type, and the operation tested.
